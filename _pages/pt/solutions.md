# Programação competitiva: soluções e materiais

Seleção inicial de **18 arquivos históricos de autoria identificada**, publicados originalmente no repositório coletivo do Clube de Programação UPF. Inclui exercícios de Codeforces e beecrowd (anteriormente URI Online Judge) e exemplos independentes de algoritmos.

A organização segue categorias próximas às utilizadas no [TCC sobre a Maratona SBC]({{ '/pesquisa/' | relative_url }}). Um código pode aparecer em mais de um assunto sem ser duplicado. A dificuldade do problema não deve ser confundida com sua categoria.

**Transparência:** cada entrada aponta para o commit histórico que adicionou o arquivo. Os códigos foram preservados, inclusive comentários que citam "URI". Os nomes de arquivos foram atualizados para o prefixo \`bee\`; exemplos \`uva\` manterão seu identificador quando houver material autoral verificado. **Compilação não equivale a aceitação pelo juiz on-line**; este acervo não apresenta essas implementações como soluções revalidadas.

**Como navegar:** abra o título de uma solução. A página dedicada explica a ideia do algoritmo em poucas frases, aponta suas limitações e mostra o código histórico. O enunciado original abre em nova aba.

Os arquivos de 2017–2018 permanecem preservados. Cada página oferece **abas C++ e Python**: uma contém o código histórico e a outra, uma adaptação didática nova (2026) com auxílio de IA, identificada explicitamente. As adaptações podem corrigir limitações conhecidas; os testes locais não equivalem a aceitação atual pelo juiz.

## Uso e procedência

Os enunciados completos pertencem às respectivas plataformas e não são reproduzidos aqui. Para estudar um programa, consulte o link do problema, o arquivo-fonte e o commit original. Arquivos históricos podem conter decisões próprias de sua época e carecer de testes completos. O projeto coletivo e seus demais participantes preservam seus respectivos créditos.
